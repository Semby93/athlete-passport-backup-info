GOOGLE DRIVE CONNECTION

Privacy notice

This notice covers the operator's backup connection to Google Drive. It is not the privacy policy for the wider Athlete Passport service.

Who operates this tool

Jordan Sembel operates Athlete Passport Backups. Contact jordan.sembel@hotmail.com about access, deletion or this notice.

Information accessed and its purpose

With the Google account owner's consent, the tool uses the Google Drive drive.file permission. This permits access to files created by the tool or explicitly selected for it. It does not request general access to all Drive files.

The tool reads the connected account email to check the intended owner, and storage quota to assess available backup capacity. It accesses permitted file and folder identifiers, metadata, permissions and contents to upload recovery copies, verify downloaded bytes, and manage approved backup-copy retention. OAuth credentials let it renew authorized access without repeated sign-in.

Storage and access

Database and protected-file archives are encrypted before they are stored in Drive. The recovery passphrase and private decryption key are not supplied to the scheduled backup runner. Encryption does not hide all metadata: file and folder names, sizes, timestamps and completion information may remain visible to the storage provider and authorized operators.

The current authorization credential is encrypted for the operator's Windows account and stored outside the source repository. The intended hosted runner will use GitHub Actions secrets for its connection credentials. Hosted credentials and automatic execution are not configured yet. Plaintext source data is processed in memory during backup capture before encryption.

Providers and sharing

Google provides sign-in, authorization and Drive storage. The planned hosted runner uses GitHub Actions to process and transfer backup data. Healthchecks.io is planned for backup-status monitoring using operational signals without backup contents. These services may process information outside Australia; Sydney-only processing has not been established for the runner.

Google user data is used only to provide and maintain this backup function. It is not sold, used for advertising or used to train generalized AI models. Operator access is limited to the backup and recovery purpose. Folder sharing is not enabled by the tool.

Athlete Passport Backups' use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

The approved operating target is to retain backup copies for 30 days once automatic retention is implemented and validated. Automatic deletion is not currently enabled. Existing rehearsal copies and synthetic test files remain until reviewed cleanup. This backup-copy policy does not set retention periods for live application records.

The account owner can remove backup files through Google Drive and revoke the tool in their Google Account's third-party connections settings. Revocation stops future authorized access; it does not delete existing files or local credentials. Contact the operator to request removal of locally stored authorization material or to coordinate backup deletion. Provider trash and retention behavior may affect when a removed copy is permanently erased.

Changes

This notice will be updated before materially different Google-data uses are introduced. Operational status must be updated when hosted processing or retention is activated.
